# 🍳 Easy Cook

**เว็บไซต์รวบรวมและจัดการสูตรอาหาร**

Easy Cook เป็นเว็บไซต์สำหรับรวบรวมและจัดการสูตรอาหาร ช่วยให้ผู้ใช้งานสามารถค้นหาสูตรอาหาร ดูรายละเอียดเมนูและวัตถุดิบ เพิ่มสูตรอาหารของตนเอง รวมถึงบันทึกสูตรอาหารที่สนใจไว้ดูภายหลังได้

## ✨ Features

- ลงทะเบียน / เข้าสู่ระบบ
- ค้นหาสูตรอาหาร
- ดูรายละเอียดสูตรอาหาร
- เพิ่มสูตรอาหาร
- แก้ไขสูตรอาหาร
- ลบสูตรอาหาร
- เลือกดูสูตรอาหารตามหมวดหมู่
- บันทึกสูตรอาหารที่สนใจ
